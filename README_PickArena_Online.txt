PICKARENA — запуск онлайн-версии (бесплатный старт)

В комплекте:
- pickarena-online.html — приложение с облачной авторизацией и хранением;
- supabase-config.js — сюда вставляются URL проекта и публичный anon/publishable key;
- pickarena_supabase.sql — схема БД, политики доступа и серверные функции.

ВАЖНО
1. Не вставляйте service_role key в браузер и не публикуйте его.
2. В Supabase создайте проект.
3. В SQL Editor выполните весь файл pickarena_supabase.sql.
4. В Authentication → Providers → Email отключите Confirm email. Это нужно потому, что username-аккаунт использует технический адрес вида username@pickarena.invalid; письма на него не отправляются.
5. В Authentication → Users создайте первого пользователя с email admin@pickarena.invalid и надёжным паролем.
6. Выполните в SQL Editor:
   insert into public.pickarena_profiles(id, username, display_name, role, league)
   select id, 'admin', 'Администратор', 'admin', 'A'
   from auth.users where email = 'admin@pickarena.invalid'
   on conflict (id) do update set role='admin';
7. В Project Settings → API скопируйте Project URL и anon/public key в supabase-config.js.
8. Загрузите три файла в один проект Vercel (или GitHub → Import в Vercel). Главная HTML-страница должна называться index.html. Поэтому переименуйте pickarena-online.html в index.html при загрузке.

ПЕРЕД ПЕРВЫМ ИСПОЛЬЗОВАНИЕМ
- Войдите администратором. Если облачная таблица пуста, приложение загрузит стартовые данные и создаст первую запись.
- Для участников используйте вкладку «Регистрация»: логин 3–24 символа (латиница, цифры, точка, дефис, подчёркивание), пароль от 8 символов.
- Первый пользовательский набор данных из исходного HTML сохранён как стартовая демо-структура. Удалите/замените демонстрационных участников и матчи в панели администратора до публичного запуска.

ОГРАНИЧЕНИЯ ЭТОЙ ПЕРВОЙ ОНЛАЙН-ВЕРСИИ
- Общие настройки турнира и изменения данных выполняет администратор.
- Прогнозы участников сохраняются отдельно в облаке и привязаны к их аккаунтам; сервер проверяет дедлайн за 5 минут.
- Вход через username реализован технически через Supabase Auth с внутренним фиктивным email. Не включайте подтверждение email.
- Приложение ещё не опубликовано: для публикации нужно создать Supabase-проект, вставить его ключи и развернуть файлы на Vercel.
